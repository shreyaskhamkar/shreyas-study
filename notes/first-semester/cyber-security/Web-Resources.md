# Web Resources for Cyber Security

This page keeps source links outside the lessons so the modules remain easy to read.

Use the labels in this order:

- **Easy second explanation:** learn the idea in another friendly way.
- **Official technical reference:** verify exact definitions or standards.
- **Practice resource:** watch, run, or solve examples yourself.

## Module 1: Cryptography

- **Easy second explanation:** [Computerphile: RSA, AES and the history of crypto](https://www.youtube.com/watch?v=Wo1iIBGnINM)
- **Official technical reference:** [NIST FIPS 197: AES standard](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.197.pdf)
- **Official signature reference:** [NIST FIPS 186-5: Digital Signature Standard](https://csrc.nist.gov/pubs/fips/186-5/final)
- **Official TLS reference:** [RFC 8446: TLS 1.3](https://www.rfc-editor.org/rfc/rfc8446)
- **Practice resource:** [CryptoHack](https://cryptohack.org/) — interactive crypto challenges.

## Module 1: Communication & Network Security

- **Easy second explanation:** [Ben Eater: ethernet, how frames work](https://www.youtube.com/playlist?list=PGdErgiyMn8hVFPf3ZeJevJux3yLfn_UPl)

## Best way to use these links

1. Read the module's simple idea and worked example.
2. Try its self-check without looking at the answer.
3. Open the easy resource if the idea is still unclear.
4. Use the official reference to verify technical details.
5. Finish with the practice resource.
