# Web Resources for Programming from First Principles

This page keeps source links outside the lessons so the modules remain easy to read.

- **Easy second explanation:** learn the idea in another friendly way.
- **Official technical reference:** verify syntax and exact language rules.
- **Practice resource:** run or modify code yourself.

## Core References

- **Easy second explanation:** [Python Tutorial](https://docs.python.org/3/tutorial/)
- **Official technical reference:** [Python Language Reference](https://docs.python.org/3/reference/)
- **Practice resource:** [Python Standard Library](https://docs.python.org/3/library/)

## Module 1: Data Types and Collections

- **Easy second explanation:** [Built-in types](https://docs.python.org/3/library/stdtypes.html)
- **Official technical reference:** [Data model](https://docs.python.org/3/reference/datamodel.html)
- **Practice resource:** Create values in the Python REPL and inspect `type(...)`.

## Module 2 to 6: Higher-Order Functions, Standard Constructs, Iteration, Lambda Calculus, First-Class Functions

- **Easy second explanation:** [Functional programming HOWTO](https://docs.python.org/3/howto/functional.html)
- **Official technical reference:** [Expressions and statements](https://docs.python.org/3/reference/expressions.html)
- **Practice resource:** Run `map`, `filter`, comprehensions, lambdas, and generator examples in Python.

## Module 7 and 8: Type Discipline and Type Hints

- **Easy second explanation:** [Type hints in the Python docs](https://docs.python.org/3/library/typing.html)
- **Official technical reference:** [The typing module](https://docs.python.org/3/library/typing.html)
- **Practice resource:** Add annotations and check them with `mypy` or Pyright.

## Module 9 and 10: User-Defined and Concrete Types

- **Easy second explanation:** [dataclasses](https://docs.python.org/3/library/dataclasses.html)
- **Official technical reference:** [class definitions](https://docs.python.org/3/reference/compound_stmts.html#class-definitions)
- **Practice resource:** Define `Student`, `Shape`, and `TrafficLight` examples in Python.

## Module 11 to 14: Recursion, Operational Semantics, Shared Behavior, Polymorphism

- **Easy second explanation:** [Recursion and algorithm thinking](https://docs.python.org/3/tutorial/controlflow.html#defining-functions)
- **Official technical reference:** [Execution model](https://docs.python.org/3/reference/executionmodel.html)
- **Practice resource:** Trace recursive functions by hand, then test them in Python.

## How to use these links

1. Read the module's simple idea and worked example.
2. Answer the self-check without looking at the solution.
3. Open the easy resource if the idea is unclear.
4. Use the official reference for exact rules.
5. Run the practice in Python.
