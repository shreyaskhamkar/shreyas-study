# Web Resources for Computational Mathematics

This page keeps source links outside the lessons so the modules remain easy to read.

Use the labels in this order:

- **Easy second explanation:** learn the idea in another friendly way.
- **Official technical reference:** verify exact definitions or theorems.
- **Practice resource:** watch, run, or solve examples yourself.

## Module 1: Logic & Type Checking

- **Easy second explanation:** [Khan Academy: Propositional logic](https://www.khanacademy.org/computing/computer-science/cryptography)
- **Official technical reference:** [MIT OpenCourseWare 6.042J: Mathematics for Computer Science](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-fall-2010/)
- **Practice resource:** [ProofWiki](https://proofwiki.org/wiki/Definition:Natural_Deduction) — worked natural-deduction proofs.

## Module 2: Well-Formed Formulae

- **Easy second explanation:** [Stanford Encyclopedia: Classical Logic](https://plato.stanford.edu/entries/logic-classical/)
- **Official technical reference:** [Pierce, Types and Programming Languages, ch. 8](https://www.cis.upenn.edu/~bcpierce/tapl/)
- **Practice resource:** Quick-check exercises on parse trees and quantifier scope.

## Module 3: Graphs and Trees

- **Easy second explanation:** [VisuAlgo: Graph Traversal & MST](https://visualgo.net/en)
- **Official technical reference:** [MIT 6.006: Kruskal & Prim notes](https://courses.csail.mit.edu/6.006/fall21/schedule/)
- **Practice resource:** [Graph Online editor](https://graphonline.ru/en/) — test Eulerian/Hamiltonian paths, MST.

## Module 4: Matrices

- **Easy second explanation:** [3Blue1Brown: Essence of Linear Algebra](https://www.youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVrdB7xdlx9M0)
- **Official technical reference:** [MIT 18.06: Gilbert Strang, Lecture notes on matrices](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)
- **Practice resource:** [Symbolab Matrix Calculator](https://www.symbolab.com/matrix-calculator) — verify inverses and determinants.

## Module 5: Vector Spaces

- **Easy second explanation:** [3Blue1Brown: Linear combinations and span](https://www.youtube.com/watch?v=k7RM-2qXLz0)
- **Official technical reference:** [MIT 18.06: Basis and dimension](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)
- **Practice resource:** [Khan Academy: Linear transformations](https://www.khanacademy.org/math/linear-algebra/linear-transformations)

## Module 6: Eigenvalues and Eigenvectors

- **Easy second explanation:** [3Blue1Brown: Eigenvalues and eigenvectors](https://www.youtube.com/watch?v=PFDu9oVAE_k)
- **Official technical reference:** [MIT 18.06: Lectures on eigenvalues by Prof. Strang](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)
- **Practice resource:** [MatrixCalc](https://matrixcalc.org/) — compute characteristic polynomial and eigenvectors.

## Best way to use these links

1. Read the module's simple idea and worked example.
2. Try its self-check without looking at the answer.
3. Open the easy resource if the idea is still unclear.
4. Use the official reference to verify technical details.
5. Finish with the practice resource.
